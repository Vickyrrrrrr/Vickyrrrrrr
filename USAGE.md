## How to use / edit

1. Clone the repository:

```bash
git clone https://github.com/Vickyrrrrrr/Vickyrrrrrr.git
```

2. Edit `README.md` or the site source files to update content, images, or links.

3. If you use a static site generator or framework, follow its specific build/deploy steps. For example, if you add a Node-based site, your workflow might run `npm ci && npm run build` and publish the build output to `dist/`.
