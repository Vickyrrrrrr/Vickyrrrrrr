# Contributing to VxkY • Vicky

Thank you for your interest in contributing! Small contributions make a big difference. Below are a few simple ways you can help.

## How to contribute

- Open an issue if you find a bug or want to request a feature.
- Fork the repository and create a new branch for your change: `git checkout -b fix/your-issue`.
- Make small, focused commits and push your branch to your fork.
- Open a pull request describing the change and why it's useful.

## Code style and guidelines

- Keep changes minimal and focused. One feature/fix per PR is preferred.
- Use clear, descriptive commit messages.
- If adding images or assets, optimize size where possible.

## Tests & validation

This repository currently contains primarily documentation and static assets. If you add code, please include basic instructions for running any tests you add.

## Contact

If you need help or want to discuss a large change, open an issue first or contact the maintainer via GitHub.
